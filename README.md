## `~/featured-projects`

### 🧠 NEXUS-AI — AI Security Research Console

An experimental security research environment combining local LLM integration, security telemetry, simulation workflows, and persistent research data.

`Python` `Ollama` `SQLite` `Security Research` `CLI`

### 🛡️ LockNLog — Asset-Aware Security Log Access

A SIEM extension focused on strict, intelligent access control over security logs. Integrates with Wazuh and explores role-based and asset-aware authorization so users access only the data they are permitted to see.

`Wazuh` `RBAC` `Asset-Based Access Control` `Security Monitoring`

### 🚗 AutoAPI-X — Connected-Vehicle API Security Lab

A simulation platform for exploring connected-vehicle API security, including the relationship between cloud-facing APIs, telematics components, vehicle commands, and in-vehicle networks.

`Python` `Flask` `SocketCAN` `SQLite` `Vehicle Security`

### 🌑 SHADOW — Connected-Vehicle Attack-Path Demonstrator

A security demonstration exploring how weak object-level authorization in a cloud/mobile vehicle interface can create a path from an API flaw to unauthorized vehicle actions. Models the chain from application and cloud API through telematics and CAN communication to an ECU.

`API Security` `IDOR / BOLA` `Telematics` `CAN` `ECU`

### 🔐 Quantum-Resilient Automotive Communication

Research and prototyping around stronger key establishment and secure communication for connected-vehicle environments, including PQC, QRNG-derived material, authenticated encryption, and key-management considerations.

`PQC` `QRNG` `AES-GCM` `Automotive Cryptography`
